You can make the following GET requests

  • /file/sample.html -- returns the content of the file sample.html
  • /json -- returns a JSON response for the /random request
  • /random -- returns index.html
  • /multiply -- multiplies two integer inputs
  • /github -- returns GitHub repo information including full_name, ID, and owner login
  • /grade -- calculates a percentage and letter grade from a score and total
  • /password -- checks password strength using a password and minimum length

Exact Example URLs

  • /multiply?num1=3&num2=4
  • /github?query=users/amehlhase316/repos
  • /grade?score=87&total=100
  • /password?password=Dragon123!&minLength=10

Custom Request Descriptions

Grade Checker

The grade request takes two arguments: score and total. It calculates the percentage earned and returns a letter grade. The score must be between 0 and the total, and the total must be greater than 0.

Password Strength Checker

The password request takes two arguments: password and minLength. It checks whether the password has an uppercase letter, a lowercase letter, a number, a special character, and meets the required minimum length.
